# SuriOS PTF

Terminal remoto para visualizar herramientas seleccionadas de PIP-SuriOS.

Proyecto previsto para ESP32-S3 y pantalla LCD TFT Estardyn de 3,5 pulgadas.

## Estado

Repositorio inicial preparado. El desarrollo funcional queda pendiente de
definir en su sprint correspondiente.

## Estructura

- `work/`: código y pruebas de desarrollo.
- `outputs/`: salidas generadas y artefactos de prueba.
